# Direction contract — Hardcore Fitness Winter Garden (draft v1)

Development-only. Never copy this into the site files.

Mode: Persuade (local gym marketing site, multi-page).

**THESIS** — The site runs on the gym's interval clock. Every page knows what is on the floor
now and next at 1401 Beulah Rd. It refuses the stock gym template: full-bleed hero, three
icon cards, stat row, testimonial carousel.

**OWN-WORLD** — Black rubber-floor ground with faint granule noise. Logo red (#E31E26) used
as whole painted-wall fields with the logo's torn stamp edge, never as a sprinkle. White
chalk text. All photography black-and-white, so red only ever comes from the brand. Red
seven-segment LED digits (authored SVG) for every time on the site. Square corners. Type:
Big Shoulders (condensed athletic display), Big Shoulders Stencil (wall signage moments,
echoes the stencil logo), Archivo (body, condensed width for labels).

**STORY** — Visitor learns: this is the Winter Garden gym itself (real address, real classes,
real coaches), the three classes, what the first hour feels like, what it costs, and that the
first class is free. They act by claiming a specific class time.

**FIRST VIEWPORT** — Left: H1 "Train hard on Beulah Road." with short sub and two actions.
Bottom right: the Floor Clock, a physical LED panel with the next class name, its start
time in LED digits, a live countdown, the coach, and "Take this class free" which pre-fills
the trial form with that exact class.

**FORM** — Own-world gym interval timer + painted stencil wall signage. Seed: none
(unavailable — Impeccable launcher not run; rules read from the skill reference files).

**SIGNATURE MOTION** — LED power-on test: on load the clock lights every segment (88:88)
for a beat, then settles to the real time, like a gym timer switching on. Reduced motion
skips it.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review,
the verdict, DESIGN.md, and every shipping raster carrying its provenance.
